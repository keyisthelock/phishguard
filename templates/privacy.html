PRIVACY & PROJECT

Your messages. Your choice.

What is retained

Scan metadata can be saved without the message text. Including a redacted preview is optional. Emails, long digit sequences, credential assignments and URL query values are masked; this is limited redaction, not a guarantee that every personal detail is removed.

Guest & account history

Guests have up to 25 recent records in bounded server memory, isolated by a random session identifier. Restarting the app clears them. Account scans remain in the database until you delete them. Use History to delete individual scans, export records or clear all your records. Clearing history also removes related feedback.

Translation

Choosing a non-English language sends the submitted text to Azure Translator. The English classifier has not been validated in other languages. Form-entered keys remain in server memory; remove them explicitly on the Azure page. Never use sensitive real-world messages for a classroom demonstration.

What detection means

This project uses a TF-IDF and Logistic Regression SMS spam baseline alongside transparent structural rules. Spam labels are a proxy for scams, not a phishing ground truth. URLs are inspected offline, never visited. Low risk does not guarantee safety.

About PhishGuard

A B.Tech project connecting machine learning, relational data, system design and cloud security. No paid analysis API is required for English scanning.
