AZURE DATA / DP-900

Relational storage

{{ 'Azure SQL active' if azure_sql else 'SQLite local mode' }}

Azure SQL Database is a managed relational database service. This app uses users and scans related by a foreign key, ACID transactions and SQL aggregate reporting.

Configure AZURE_SQL_CONNECTION_STRING and install ODBC Driver 18 to switch providers. Local data is not automatically migrated.
